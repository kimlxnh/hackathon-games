# Rock Paper Scissors

## To play rock, paper, scissors
Our game is a simple rock, paper and scissors game. It takes a user input and plays against a bot, returning both user and computer results and whether the user has won, lost or need to try again.

## Rules:

- Rock beats paper, and loses against scissors
- Paper beats rock, and loses against scissors
- Scissors beats paper, and loses against rock

By collaborators: Kim Vu and Luke Oakins.
